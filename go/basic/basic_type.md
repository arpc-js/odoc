# 1. 数字类型
数字类型用来存储数字，主要包括 **整型（整数类型 int）** 和 **浮点型（小数类型 float64）**。
> 注意：整型和浮点型变量的 **默认值为 0**（整数为 0，浮点为 0.0）。

## 1.1 整型变量示例:
```go
func main() {
    age :=18//短变量声明赋值,年龄是整数
    fmt.Println("age:", age) //打印年龄age 结果是整数18
}
```
### 1.2  浮点型变量示例:
```go
func main() {
    score :=99.5//短变量声明赋值,成绩是小数
    fmt.Println("score:", score) //打印变量的值 结果是18
}
```

# 2. 字符串类型（string）
字符串类型用来存储文本，例如名字、消息、描述等。
> 注意：字符串类型变量的值要加双引号,默认值为 **""**（空字符串）。

## 2.1 字符串变量示例
```go
func main() {
    name := "张三"      // 短变量声明赋值，表示名字
    fmt.Println("name:", name) // 输出：张三!
}
```
# 3. 布尔类型（bool）
布尔类型用来表示 **真（true）** 或 **假（false）**，常用于条件判断和逻辑运算。
> 注意：布尔类型变量的默认值为 **false**。


## 3.1 布尔变量示例
```go
func main() {
    isAdmin := true      // 短变量声明赋值，表示是否是管理员,true是管理员，false不是管理员
    fmt.Println("isAdmin:", isAdmin)       // 输出：true
}
```
