# 第一章：HTML 简介

## 什么是 HTML
HTML（HyperText Markup Language）是**超文本标记语言**，用于构建网页的内容和结构。  
它是网页的骨架，决定了网页中的文本、图片、链接、表单等元素的排布。

## HTML 的作用
- **网页结构**：定义网页标题、段落、列表、表格等内容
- **内容展示**：嵌入图片、音视频、超链接等
- **网页交互**：配合表单收集用户输入，供后端处理
- **语义化标记**：利于搜索引擎优化（SEO）和辅助设备访问

## HTML 基本示例
```html
<!DOCTYPE html>
<html>
  <head>
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>欢迎学习 HTML！</h1>
    <p>这是一个段落，用于展示文本内容。</p>
    <a href="https://www.example.com">访问示例网站</a>
    <img src="logo.png" alt="网站logo" width="200">
  </body>
</html>
